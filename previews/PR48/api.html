API reference ​

SpinDoctor Module
julia
SpinDoctor

Diffusion MRI simulation toolbox: finite element simulations of the Bloch-Torrey equation and related models in geometries of cells and extracellular space.

The main functions and types are exported. Lower level building blocks (meshes, assembly, geometry files, gradient sequence internals, callback hooks) are public but not exported, and are used as SpinDoctor.name.

source

The main functions and types are exported. The building blocks listed under Public, not exported are used with the module name, e.g. SpinDoctor.FEMesh.

Setup recipes and geometry ​

SpinDoctor comes with recipes for creating finite element meshes of plates, slabs, disks, cylinders, spheres, polyhedra and neurons, possibly immersed in an extracellular space (ECS).

Setup recipe for stacked plates in 2D, with the given widths along the x-axis and extent depth along the y-axis. The triangles have an area of at most refinement.

SpinDoctor.DiskSetup Type
julia
DiskSetup(;
    ncell = 3,
    layersizes = [1.0],
    rmin = 2.0,
    rmax = 6.0,
    dmin = 0.2,
    dmax = 0.6,
    nsidewall = 12,
    ecs = NoECS(),
    refinement = Inf,
)

Setup recipe for ncell disks in 2D, possibly immersed in an extracellular space ecs.

  • The radii are between rmin and rmax, and the gaps between neighboring cells between dmin and dmax times the mean radius (see create_cells).

  • Each cell has layers with the relative radii layersizes (increasing, the last one being one), e.g. [0.6, 1.0] for an axon with a myelin sheath.

  • A cell of mean radius has nsidewall points on its boundary.

  • The triangles have an area of at most refinement.

SpinDoctor.VoronoiSetup Type
julia
VoronoiSetup(;
    ncell = 20,
    boxsize = 20.0,
    fraction = 0.8,
    lloyd = 10,
    meshsize = boxsize / ncell^(1 / 3) / 8,
    refinement = Inf,
)

Setup recipe for ncell polyhedral cells in a periodic cubic box of side boxsize: the Voronoi cells of random seed points (made more regular by lloyd Lloyd iterations), separated by a uniform gap such that the cells fill the volume fraction fraction. The cells are cut by the faces of the box, their periodic images enter on the opposite faces, and the extracellular space fills the gaps (as for a PeriodicBoxECS).

Unlike packings of spheres, which cannot fill more than about 64 % of the volume, polyhedral cells can fill any fraction below one. The surfaces are triangulated with triangles of size meshsize, such that the opposite faces of the box have the same triangles, and the tetrahedra have a volume of at most refinement. The mesh is periodic, so that periodic boundary conditions may be used with assemble_matrices(model; periodic = true). The coefficients are given as for a SphereSetup with one layer.

SpinDoctor.PeriodicBoxECS Type
julia
PeriodicBoxECS(; fraction = 0.5)

Extracellular space of a sample of a periodic tissue. The box of the cell configuration (cells.box, e.g. from periodic_packing) is filled with the cells, cut by its faces, and their periodic images, and the ECS fills the rest. Unlike BoxECS, there is no free layer of ECS along the faces, and the geometry is periodic. The mesh is periodic too (the opposite faces of the box have the same points), so that periodic boundary conditions may be used with assemble_matrices(model; periodic = true); otherwise, the box faces are impermeable boundaries.

If no cell configuration is given to create_geometry, a packing with the cell volume fraction fraction is created (see create_cells). Available for disks and cylinders. Fractions up to about 0.8 (counting the gaps as part of the cells) require many cells, e.g. twenty or more. As in the other recipes, the disks are polygons inscribed in the circles (with nsidewall sides for the mean radius), so that their area is slightly smaller than that of the circles (by 1.1 % for 24 sides).

source
SpinDoctor.periodic_packing Function
julia
periodic_packing(
    radii;
    dim = 2,
    fraction,
    gap = 0.0,
    rng = Random.default_rng(),
    maxiter = 200_000,
)

Pack disks (dim = 2) or spheres (dim = 3) with the given radii in a periodic box, without overlaps and with gaps of at least gap between neighbors. The box size is chosen so that the cells fill the volume fraction fraction of the box.

The positions are found by a collective rearrangement: starting from random positions, the radii grow towards their final values while the overlaps are removed by moving overlapping pairs apart. Random packings of polydisperse disks jam at fractions of about 0.84 and spheres at about 0.64 (counting the gaps as part of the cells); higher fractions cannot be reached. If the packing jams (or takes more than maxiter relaxation sweeps) within one percent of the final radii, the radii are reduced accordingly (with a warning); otherwise an error is thrown.

Returns a cell configuration (; centers, radii, box), with centers of size (dim, ncell) inside box = (lower, upper), for create_geometry with a PeriodicBoxECS.

source
SpinDoctor.create_geometry Function
julia
mesh, surfaces, cells = create_geometry(
    setup;
    cells = nothing,
    rng = Random.default_rng(),
    cache = nothing,
    savedir = nothing,
    recreate = false,
)

Create the cells, the surface triangulation and the finite element mesh of setup.

Random cell configurations are drawn from rng. For disks, cylinders and spheres, a cell configuration (; centers, radii) (as returned by create_cells) may be given instead, with centers of size (dim, ncell) and radii of length ncell, e.g. from a packing algorithm.

By default, no files are written. The geometry may be stored in one of two ways:

  • cache: a JLD2 file (requires using JLD2, see save_geometry). If the file exists and was created for the same setup (and cells), the geometry is loaded from it. Otherwise, it is created and saved.

  • savedir: a directory with text files in the TetGen format, compatible with the MATLAB version of SpinDoctor (cells, mesh.node, mesh.poly, mesh.1.node, mesh.1.face, mesh.1.ele), and a description of the setup (setup). Existing files are reused if they were created for the same setup.

With recreate = true, the geometry is always created, and the files are overwritten.

Model and matrices ​

SpinDoctor.coefficients Function
julia
coefficients(setup; D, T2, rho, kappa, gamma)

Distribute the coefficients over the compartments and boundaries of setup, and return them as a named tuple (; D, T2, rho, kappa, gamma), from which a Model may be created. The coefficients are given as follows:

  • plates and slabs: D, T2 and rho are vectors with one value per plate, and kappa = (; interfaces, boundaries) contains the permeabilities between consecutive plates and the relaxivities of the outer boundaries of the plates;

  • disks, cylinders and spheres: D, T2 and rho are named tuples (; cell, ecs), with one value per layer for cell, and kappa = (; cell_interfaces, cell_boundaries, cell_ecs, ecs) contains the permeabilities between consecutive layers, the relaxivities of the outer boundaries of the layers (e.g. the ends of extruded cylinders), the permeability between the cells and the ECS and the relaxivity of the outer boundary of the ECS;

  • neurons: D, T2 and rho are named tuples (; neuron, ecs), and kappa = (; neuron_ecs, neuron, ecs).

The diffusion tensors D are matrices (µm²/µs), T2 times in µs, permeabilities and relaxivities in µm/µs and gamma the gyromagnetic ratio (see Model).

SpinDoctor.Model Type
julia
Model(; mesh, rho, D, T2, kappa, gamma)

Finite element discretized biological model:

  • mesh: finite element mesh split into compartments (FEMesh);

  • rho: initial spin density of each compartment;

  • D: diffusion tensor of each compartment (µm²/µs);

  • T2: T2 relaxation time of each compartment (µs);

  • kappa: permeability of each boundary (µm/µs), for interfaces between compartments and for the outer boundaries (as a boundary relaxivity);

  • gamma: gyromagnetic ratio (rad / (µs µm T/m), 2.67513e-4 for water protons).

The coefficients for a setup recipe may be created with coefficients.

SpinDoctor.assemble_matrices Function
julia
assemble_matrices(model; periodic = false)

Assemble the finite element matrices of model.

Returns a named tuple with

  • the global (block diagonal) mass matrix M, stiffness matrix S (with the diffusion tensors), relaxation matrix R (M divided by T2), first order moment matrices Mx (, one per axis d) and flux matrix Q (permeable interfaces and outer boundaries, see assemble_flux_matrix);

  • the compartment blocks M_cmpts, S_cmpts and Mx_cmpts;

  • the surface integrals G, one matrix per compartment with the integrals   over the boundary of the compartment with outward normal n (one row per point, one column per axis);

  • the compartment volumes.

With periodic = true (or one Bool per axis), the mesh is a sample of periodic tissue in its bounding box, such as the meshes of PeriodicBoxECS and VoronoiSetup, and each compartment is periodic along the given axes: the points on opposite faces of the box are identified. The solvers then use periodic boundary conditions instead of impermeable box faces. The matrices are still those of the whole mesh, and the named tuple also contains

  • the prolongation P from the periodic points to all the points (see periodic_restriction), its compartment blocks P_cmpts, and the index of one point for each periodic point (masters);

  • the matrices Cx (, one per axis d, see assemble_derivative_matrix).

Without periodicity, these fields are nothing.

Solvers ​

SpinDoctor allows for considering a wide range of diffusion MRI problems, each with its own solver function.

SpinDoctor.solve_btpde Function
julia
solve_btpde(model, matrices, gradient, solver = ThetaSolver(); callbacks = [])

Solve the Bloch-Torrey partial differential equation using P1 finite elements in space and the time stepping solver, and return the magnetization at the echo time.

The time stepping is a ThetaSolver. With OrdinaryDiffEq, its ODE algorithms may also be used, e.g. using OrdinaryDiffEqBDF; solve_btpde(model, matrices, gradient, QNDF(); abstol, reltol).

The callbacks (see AbstractCallback) are called after each time step.

With periodic matrices (assemble_matrices(model; periodic = true), only with ThetaSolver), the compartments are periodic in the box of the mesh: the magnetization is  , where m is periodic and   is the wave vector (see wavevector). The time steps then use one factorization per interval only where the gradient is zero.

source
SpinDoctor.ThetaSolver Type
julia
ThetaSolver(; theta = 0.5, timestep = nothing, arraytype = Array)

Theta-scheme time stepping for the BTPDE (theta = 0.5: Crank-Nicolson, second order; theta = 1: implicit Euler, first order), with steps of at most timestep in each characteristic interval of the gradient (by default a thousandth of the echo time). The gradient is evaluated at the middle of each step.

For interval-wise constant scalar gradients (e.g. PGSE, DoublePGSE), the linear systems are solved with one sparse factorization per interval. For other gradients, they are solved with GMRES, preconditioned with a factorization of the diffusion part (one per step size), so that the matrices are not refactorized at every step.

With arraytype = CuArray (after using CUDA, CUDSS), the time stepping runs on an NVIDIA GPU, with the sparse direct solvers of cuDSS.

SpinDoctor.solve_hadc_tensors Function
julia
solve_hadc_tensors(
    model,
    matrices,
    profile;
    timestep = echotime(profile) / 1000,
    arraytype = Array,
)

Compute the apparent diffusion tensor of each compartment for the time profile profile, using the homogenized ADC model (HADC) [14]. The ADC in the direction u is u' * D * u.

The HADC model assumes impermeable compartment boundaries: permeabilities, initial spin densities and T2 relaxation are not taken into account. The ADC of a sample may be estimated by weighting the compartment ADCs with compartment_weights.

The auxiliary diffusion problem is solved with the Crank-Nicolson scheme, with steps of at most timestep in each characteristic interval of the profile. By linearity, the ADC in any direction follows from one solve per axis. With arraytype = CuArray (after using CUDA, CUDSS), it is solved on an NVIDIA GPU.

With periodic matrices (assemble_matrices(model; periodic = true)), the compartments are periodic, and the faces of the box are not boundaries.

SpinDoctor.solve_karger Function
julia
solve_karger(model, difftensors, gradient; timestep)

Solve the finite pulse Karger model (FPK) using precomputed effective diffusion tensors difftensors (one per compartment), and return the compartment signals.

The compartments exchange magnetization through their interfaces with rates given by the permeabilities, interface areas and volumes. The compartment signals are integrated with a fourth order Magnus method, with steps of at most timestep within each characteristic interval of the gradient sequence.

SpinDoctor.periodic_restriction Function
julia
P, masters = periodic_restriction(points, facets, box, dims; atol)

Identify the points on opposite faces of the periodic box = (lower, upper) along the axes dims: the points of the boundary facets on an upper face are images of the points of the facets on the lower face, translated by the box size (up to atol). Points that touch a face without a facet on it (e.g. the vertex of a cell) are not identified.

SpinDoctor.assemble_flux_matrix Function
julia
assemble_flux_matrix(model; symmetrical = false)

Assemble the global flux matrix Q of the permeable interfaces between compartments and of the relaxing outer boundaries.

At an interface with permeability kappa between compartments with initial spin densities rho1 and rho2, the coefficients on each side are 2 rho2 / (rho1 + rho2) kappa and 2 rho1 / (rho1 + rho2) kappa, so that the equilibrium magnetization has no net flux. With symmetrical = true, kappa is used on both sides.

SpinDoctor.create_surfaces Function
julia
create_surfaces(setup, cells)

Create the surface triangulation of a setup with the cell configuration cells (for neurons: the file name of the volume mesh), to be meshed by create_mesh.

Returns a named tuple containing:

  • points: the points (size dim, npoint);

  • facets: the triangles (edges in 2D) (size dim, nfacet);

  • facetmarkers: the boundary number of each facet;

  • regions: points inside the regions (size dim, npoint), by default one per region;

  • regionmarkers (optional): the region number of each of these points, for regions with several parts;

  • box and meshsize (samples of periodic tissue): the box (lower, upper), whose opposite faces have the same points, and the size of the facets. The mesh keeps the facets on the box (in 2D) or all the facets (in 3D), so that the mesh is periodic.

The boundaries between n regions are numbered with the interfaces between regions i < j first (row by row: 12, 13, ..., 1n, 23, ...), followed by the outer boundaries of the regions 1, ..., n.

source
SpinDoctor.create_mesh Function
julia
create_mesh(surfaces, refinement)

Create a global finite element mesh of the regions enclosed by the surface triangulation surfaces (see create_surfaces), with TetGen in 3D and Triangle in 2D. The elements have quality constraints, and a maximum volume (area in 2D) refinement if it is finite. For samples of periodic tissue (with a box), the facets on the box (in 2D) or all the facets (in 3D) are kept as they are, so that the mesh is periodic.

Returns a named tuple with points, facets and facetmarkers (boundary numbers), and elements and elementmarkers (region numbers).

AbstractTimeProfile{T}

Time profile f(t) of a gradient sequence (normalized to a maximum of one).

A time profile implements a calling method returning its value at time t, and intervals, returning the characteristic times at which the profile may be discontinuous (the last one being the echo time). It can optionally implement integral and int_F2, which are otherwise computed numerically.
